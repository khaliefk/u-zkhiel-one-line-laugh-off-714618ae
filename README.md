One funny line for the [One-Line Laugh-Off](https://make.fun/bounty/u-zkhiel-one-line-laugh-off-714618ae) bounty on make.fun.

## How it works

Run `main.py`. It writes exactly one joke, a single line of 99 characters, to `/output/entry.txt`. No network, no input, no setup notes, just the line.

## The line

> My therapist asked what brings me joy, so I showed her my search history and now she needs therapy.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
